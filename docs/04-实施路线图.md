## 八、风险与缓解

| 风险 | 影响 | 概率 | 缓解措施 |
|------|------|------|----------|
| LLM API 不稳定 | 推理/立场分析失败 | 中 | 添加重试机制 + 降级方案 + 备选模型 |
| 爬虫被目标网站封禁 | 外部数据采集中断 | 高 | 多 IP 池 + 限速 + 合规爬取 |
| 数据迁移失败 | 数据丢失 | 低 | 备份数据库 + 分批迁移 + 回滚脚本 |
| 前端兼容性 | 用户体验下降 | 低 | 渐进式迁移 + 向后兼容 |
| 立场分析准确率不够 | 推理结果偏差 | 中 | Prompt 迭代优化 + 人工修正兜底 |
| 性能下降 | 响应慢 | 中 | 异步处理 + 缓存 + 并行调用 |

## 九、验收标准

### 功能验收

- [ ] 同一证据在不同议题下有不同立场
- [ ] 用户可以手动修正立场
- [ ] AI 自动分析立场准确率 > 80%
- [ ] AI 自动提炼洞察，关联到证据
- [ ] 用户可以创建/确认/质疑洞察
- [ ] 数据源可配置爬虫采集外部数据
- [ ] 正方使用内部证据+洞察构建论据
- [ ] 反方使用外部证据+洞察构建反驳
- [ ] 裁判综合内外视角生成决策卡
- [ ] 决策卡引用洞察和证据
- [ ] 决策卡置信度合理

### 性能验收

- [ ] 单条立场分析 < 3s
- [ ] 批量立场分析（20条）< 10s
- [ ] 洞察提炼 < 5s
- [ ] 完整对抗推理 < 30s
- [ ] 页面加载 < 2s
- [ ] 数据源同步任务 < 5min

### 兼容性验收

- [ ] 旧数据正确迁移（stance 从 evidence → issue_evidence）
- [ ] 旧 API 继续工作（兼容模式）
- [ ] 前端无报错
- [ ] 决策卡新旧版本均可正常展示
