欢迎来到ResearchOS v3.1。虽然系统背后的“神经博弈”听起来架构很硬核，但作为用户，你的核心目标只有一件事：通过AI的对抗推理，让决策不再凭直觉。为了快速帮助上手，我为你准备了一份《ResearchOS新手极简操作手册》。💡第一步：理解核心概念在开始操作之前，你需要知道系统里的三个“角色”是如何为你打工的：角色职责它的“态度”正方（辩护人）挖掘内部数据（如表格、访谈）的价值“我们有这些优势，应该这么做！”反方（批评家）收集外部信号（如竞品、舆情）的风险“外面情况很复杂，现场有风险！”裁判（法官）综合两方观点，识别盲区，给出最终建议“兼听则明，这是最合理的行动方案。”🚀 快速上手五部曲1.创建议题塔（Issue Tower）进入系统后，点击“发起新的议题”。你需要定义一个具体的决策问题。新手技巧：问题越具体越好。❌错误示范：“我们公司未来如何发展？”✅ 正确示范：“Q3用户增长园区，是否应该调降8%的价格？”2.汇聚证据（Evidence Depot）系统会自动将你的席位与证据库进行关联：内部证据：导入你现有的视频、深度访谈或内部报告。外部证据：系统爬虫会自动从社媒、竞品监控和行业报告中采集相关信号。3.提炼洞察（洞察提取器）AI 会从几十条碎片证据中自动总结出几条结论（Insight）。你可以点击每一条“洞察”，查看它是根据哪几条原始数据生成的。如果你觉得AI的总结不规范，可以手动修改或标记“质疑”。4.开启对抗推理（决策剧场）这是最精彩的部分。点击“开始推理”，你将在界面上看到正方和反方代理的博弈过程。天平表示：随着证据的切入，系统将实时展示置信度的偏向。盲区检测：如果有证据证明严重缺席，裁判特工会发布预警。5.获取决策卡与行动项（判决）推理结束后，系统会吐出一张“决策卡”：最终建议：明确告诉你是“采纳”还是“拒绝”。行动项 (Action Items)：自动划分出接下来谁该做什么事情（如：张三去设计 A/B 测试）。🛠️给“小白”的特别忠告不要跳过“回看”（回顾）：当行动完成后，一定要回系统记录一下实际效果。这样系统才能把这次经验转化成“新证据”，下次决策它就会变得更加聪明。观察“置信度”：如果决策卡的置信度低于60%，说明矛盾很大或严重不足，此时建议点击“补充调研”，不要盲目执行。立场是相对的：同一条证据，在立场A里可能是“支持”，在立场B里可能是“反对”。放手让AI去分析，你只需做最后的审核。现在，尝试在你的“剧场中心”塑造一个真实的业务疑问吧！
